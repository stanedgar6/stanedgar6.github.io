Privacy Policy — Sui Checkpoints

Last updated: 2026-10-03

The "Sui Checkpoints" application uses the Google Drive API to store and retrieve files (compressed Sui checkpoint batches) in the Google Drive account of the user who authorizes it.

  • The application only accesses files it creates itself in the authorizing user's Drive.
  • No personal information is collected, and no data is read from files the application did not create.
  • Data is never shared with or transferred to third parties.
  • All data stays in the authorizing user's own Google Drive and can be deleted at any time.
  • Access can be revoked at any time at https://myaccount.google.com/permissions
